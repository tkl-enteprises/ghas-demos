# Security Policy

## 1. This is an intentionally-vulnerable repository

The vulnerabilities, secrets, and known-vulnerable dependencies in this repo are **placed here on purpose** as the curriculum for a hands-on workshop organized into five pillars: **Code Security**, **Secret Protection**, **Supply Chain**, **Governance**, and **Code Quality**. Code Quality is distinct from Code Security even though both use CodeQL infrastructure. Every CodeQL alert, secret-scanning hit, and Dependabot advisory you see is the lesson — not a bug.

**Please do not report demo vulnerabilities.** They are the feature, not the flaw.

## 2. Issues with the workshop content itself

If you find a real (non-curriculum) problem with the workshop materials — a typo, a broken link, a lesson whose steps no longer work, or instructions that contradict the current GitHub UI — please **open a public issue** in this repo. Public issues are fine because nothing here is sensitive.

## 3. Real GitHub product vulnerabilities

If your finding is about **GitHub Code Security, GitHub Secret Protection, or another GitHub product** rather than this demo, report it through GitHub's HackerOne program: <https://hackerone.com/github>. Do not file product-level reports here.
